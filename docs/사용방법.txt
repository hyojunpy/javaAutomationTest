조리지시서 변환기

1. ZIP을 모두 압축 해제한 뒤 Jungwha_Converter.exe를 실행하세요.
2. HWP 파일을 선택하거나 창에 끌어다 놓으세요.
3. 표시되는 유형·연령과 Excel 저장 위치를 확인하세요.
4. 조리지시서 만들기를 누르고 완료될 때까지 기다리세요.
5. 완료 후 Excel 열기로 결과의 메뉴·재료·수량을 확인하세요.

일반형 변환에는 수 분 걸릴 수 있습니다. 경과 시간과 처리 단계를 확인하세요.
파일명 예시: 2026년 2월 일반형(만1-2세).hwp
HWPX는 지원하지 않습니다. 파일명과 문서 구조는 기존 예시 규칙을 따릅니다.
실행 파일과 app, runtime, input 폴더를 함께 유지하세요. Java 설치는 필요하지 않습니다.
오류가 발생하면 작업 내역과 표시된 저장 경로를 확인하세요.
